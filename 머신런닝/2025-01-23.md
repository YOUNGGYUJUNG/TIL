1. 메모리
- LLM은 이전 대화를 기억하고 이를 바탕으로 대화를 지속적으로 나아가야함
- 그래서 내부적으로 이전 대화 내용을 프로프트에 삽입하여 사용하는 메모리 컴포넌트가 필요
- 다 저장하기에는 비용문제로 여러기법이 존재하는데  예로 오래된 대화 내용은 LTM(장기메모리)에 간단 요약해서 저장하고 STM(단기 메모리)에 최근 대화 내용을 저장하는 방법이 있다.

## 랭체인

- 랭체인의 특징
    - 랭체인을 사용하여 개발된 LLM은 종류와 상관없다.
    - 여러 처리 단계를 간편하게 구현가능
    - 외부의 DB, 벡터 DB,  검색 엔진등 다양한 외부 컴포난트와의 통합이 쉬움
    - 운영에 대한 필요한 기능을 개발할 수 있다.

- 랭체인의 주요 구성요소
    - Model IO : LLM모델의 입력과 출력을 관리, LLM의 성능을 최적화
    - Retrieval : 문서 데이터베이스에서 질문과 관련된 정보를 검색하는 역할, 외부 데이터 검색하여 정확성을 높임
    - Agent Tooling : 외부 시스템과의 연동을 지원하는 역할을 한다. 실시간 데이터 검색, 내부DB조회등등

- Model IO 구성요소
    - Model : LLM모델을 추상화하여 제공, 입력받은 컴포넌트에 대해 텍스트 답변을 리턴하는 기능, LLM 기반의 ChatModel를 제공하여 여러 문장을 대화 문장으로 반환하는 모델을 사용하여 챗봇을 개발할 수 있다.
    - Prompt : 예를 들어 한국의 관광지를 물어보고 일본의 관광지를 물어볼때 “한국”의 자리를 “일본”으로 대체함으로써 비용을 줄여주는 역할이다.
    - chain : 다단계 흐름제어를 시켜주는 기능이다.
    - memory : 컨택으스의 요약과 저장을 하고 답변할 때 프롬프트에 삽입한다.
    - Agent : 외부 서비스와 연동하여 답변을 할 때 적절한 툴을 실행한다.
    - Retrieval(검색) : 문서 DB에서 검색하여 문장을 찾고 LLM이 답변하게 하는 구조이다.
