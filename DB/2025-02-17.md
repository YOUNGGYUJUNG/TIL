# Redis

## Redis 캐시로 사용하는 법

Redis : 데이터의 원래 소스보다 더 빠르고 효율적으로 액세스할 수 있는 임시 데이터 저장소

Redis는 한번이상 사용할 때 효율적임

key-value 형태 저장

인메모리 저장(ram) → 그래서 매우 빠름(지연속도 감소, 처리량 증가)

## 캐싱 전략

읽기 전략

- Look-Aside

캐시를 찾는 데이터가 없을 때만 DB에서 찾는 것

다만 Redis가 장애가 오거나 처음 실행할 때 DB에 부하가 올 수 있음

→ Cache Warming(DB에서 미리 캐시에 데이터를 넣음)을 씀

쓰기 전략

- Write-Around

DB에만 저장, 장애가 발생할 경우 캐시에 저장

- Write-Through

저장할 때 DB와 캐시 둘다 저장 → expire time을 써서 저장기간 설정

## Redis의 데이터 타입 활용

제공하는 데이터 타입

- 문자
- 비트맵
- 리스트
- 해쉬
- 세트
- 정렬 세트
- 하어퍼로그로그스
- 스트림

## 활용

- 카운팅
    - 단순 증감 연산 : String의 increment 함수를 쓰면 간단히 구현 가능
    - 비트 연산 : 데이터 저장공간 절약, 정수 데이터만 카운팅 가능
    - 하이퍼로그로그스 : 대용량 데이터를 카운팅 할 때, 적절 저장할 때 12KB 사이즈 고정
- 메시지 큐
    - List : Blocking 기능을 이용해  Evenet Queue로 사용 LPUSHX or RPUSHX 같은 커맨드를 사용하면 이미  캐싱되어 있는 피드에만 신규 트위 저장
    - stream : 로그를 저장하기 가장 적절한 자료구조 /  append-only /  시간 범위로 검색, 신규 추가 데이터 수신,카프카처럼 소비자별 다른 데이터 수신

## 래디스 영구저장 방법

레디스의 불안 요소

- 서버 재시작 시 모든 데이터 유실
- 복제 기능을 사용해도 사람의 실수 발생 시 데이터 복원 불가
- 그래서 적절한 데이터 백업 필요

Redis 영구저장 활용

- AOF파일은 계속 저장하기 떄문에 지속적인 압축이 필요함
- RDB와 AOF나누어 저장

RDB

- 자동 : redis.conf 파일에서 SAVE옵션
- 수동 : DGSAVE 커맨드를 이용해 cli 창에서 수동으로 RDB파일 저장 (save커맨드 절대 사용X)

AOF

- 자동: redis.conf파일에서 auto-aof-rewrite-percentage옵션
- BGREWRITEAOF커맨드를 통해 CLI창에서 수동으로 AOF파일 재작성

사용 기준

- 백업은 필요하지만 어느 정도 데이터 손실 OK → RDB, SAVE커맨드 옵션 적절히 사용
- 장애 상황 직전까지의 모든 데이터가 보장되어야 할 경우 → AOF
- 제일 강력한 내구성이 필요한 경우 → 둘다 사용

아키텍터 구조

- 리플리케이션 구조

마스터와 레플리카노드 두개의 구조

HA기능이 없으므로 장애 상황시 수동복구

- Sentinel 구조

마스터가 비정상 상태일 때 자동으로 페일오버

연결 정보 변경 필요 없음

장애 상황시 레플리카가 마스터가 됨

- cluster 구조

마스터와 레플리카노드 3쌍이 필요함

샤딩기능이 있음

모든 노드가 서로 감시

마스터가 비정상 상태일 때 자동으로 페일오버

## 사용하면 안되는 커맨드및 설정

- keys는 사용 X → scan으로 대체

싱글 스레드이기 때문에 오래걸림

- STOP-WRITES-ON-BGSAVE_ERROR = NO(default=yes)

RDB 파일 저장 실패시 redis로의 모든 write불가능

- MAXMEMORY-POLICY = ALLKEYS-LRU

redis를 캐시로 사용할 때 Expire Time 설정 권장

메모리가 가득 찼을 때 저장안한다는 커맨드 안하면 전체가 지워짐

- TTL 값을 너무 작게 설정한 경우

duplicate write&read가 발생해 비효율및 장애로 이어짐

- MaxMemory값 설정

실제 메모리의 반값으로 설정 → 가상메모리를 돌리기 때문

- 물리적으로 사용되고 있는 메모리를 모니터링

알 수 있었다.다음 프로젝트는 Redis의 구조를 잘 구성해서 장애가 발생해도 견딜 수 있는
