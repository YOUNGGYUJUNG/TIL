## NGINX란?

웹 서버로 사용되고 그 외에도 역방향 프록시, 로드 밸런서, 캐시 서버등 다양한 수행하는 소프트웨어

1. 웹 서버
- 역할

클라이언트의 요청을 받아서 HTML, CSS, JavaScript 등의 정적 파일을 제공하는 역할

- 특징
    - 빠르고 효율적 : 적은 자원으로 많은 요청을 처리할 수 있도록 설계
    - 동시 접속 처리 : 한 번에 많은 사용자 요청을 효율적으로 처리

1. 역방향 프록시 Reverse Proxy
- 역할

클라이언트의 요청을 받아서 실제 애플리케이션 서버(Spring, Node,js 등등)로 전달

- 특징 :
    - 보안 강화 : 클라이언트와 애플리케이션 서버 사이에 위치함으로써 직접 서버의 IP가 노출X
    - 부하 분산 : 여러 서버에 요청을 분산시켜,  한 서버에 과부하가 걸리지 않도록 도와줌
    - 캐싱 : 자주 요청되는 콘텐츠를 미리 저장해두고 빠르게 응답할 수 있음

1. 로드 밸런서 Load Balancer
- 역할

여러 대의 서버에 트래픽을 고르게 분산시켜, 서버 중 하나에 부하가 집중되지 않도록 함

- 특징
    - 시스템 안정성 : 서버 장애 시에도 다른 서버로 요청을 분산해 시스템이 중단안되게 함
    - 확장성 : 사용자가 늘어날 때 서버를 추가하여 대응

1. **SSL/TLS 처리**

보안 연결을 위한 인증서 관리와 암호화 처리

## 느낀점

서버를 로컬로만 돌여서 잘 모르고 넘어가는 부분도 있었는데 스프링 시큐리티를 공부하면서 보안을 어떻게 해야하는지 그리고 더 강화해야하는지 막연한 상태였는데 네트워크에서도 보안을 걸고 트래픽을 제어하면서 점점더 단단한 사이트를 만들 수 있을것 같다.
